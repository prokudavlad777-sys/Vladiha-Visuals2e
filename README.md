# boosterik 1.12

Одна програма, три розділи. Зверху напис **boosterik 1.12** — по кліку відкривається меню:

| Розділ | Що робить |
|---|---|
| **Візуалізація** | Приціл-оверлей поверх гри: 8 вбудованих прицілів + власні з папки `Custom\Crosshair` (PNG/JPG/BMP/GIF), колір, розмір, товщина, проміжок, прозорість, анімація (обертання / пульсація) |
| **Оптимізатор** | Rust, CS 2, ARK, Minecraft, World of Tanks, GTA V: високий пріоритет, ядра CPU, очищення RAM, схема «Висока продуктивність» + ігровий режим, мережа (Nagle/ACK), тимчасові файли. Кнопка «Відновити», автооптимізація при запуску гри |
| **Кольорокоректор** | Гама, насиченість, експозиція, контраст, температура, тон + прев'ю-сфера. «Застосувати» змінює колір усього екрана |

Іконка exe — `res/boosterik.ico` (її ж видно зверху в меню).

## Збірка на GitHub
1. Завантаж увесь вміст цієї папки в репозиторій (разом з `.github/workflows/build.yml`).
2. Відкрий **Actions → Build boosterik.exe** (запуститься сам після push, або натисни *Run workflow*).
3. Після завершення: у запуску внизу **Artifacts → boosterik-1.12** — там `boosterik.exe`.
4. Хочеш готовий реліз — зроби тег: `git tag v1.12 && git push origin v1.12`, exe з'явиться у *Releases*.

Локально (Visual Studio / Build Tools): `cmake -S . -B build -A x64` → `cmake --build build --config Release`.

## Нотатки
- exe просить права адміністратора (потрібно для реєстру мережі, схеми живлення, очищення RAM).
- Власні приціли: клади картинки в `Custom\Crosshair` поруч з exe, натисни «Оновити список».
- Оверлей прицілу та кольорокорекція працюють у віконному режимі / borderless. В ексклюзивному повноекранному режимі гра може їх ігнорувати.
- Налаштування зберігаються в `%APPDATA%\Boosterik\settings.ini`.
- Мережеві зміни (Nagle/ACK) діють після перепідключення до мережі.
